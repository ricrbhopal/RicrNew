# RicrNew

Full-stack React + Node.js application. This repository contains a Vite-powered React client (in `client/`) and an Express + Mongoose API server (in `server/`).

## Contents

- `client/` — React frontend built with Vite, Tailwind CSS and React Router.
- `server/` — Express API server using Mongoose, Cloudinary, Multer and dotenv.
- `README.md` — this file.

## Quick start

Prerequisites:

- Node.js (recommended v18+)
- npm 


## Tech stack

- Frontend: React (Vite), Tailwind CSS, React Router, Axios
- Backend: Node.js, Express, Mongoose (MongoDB), Multer, Cloudinary


## Contact / License

For questions, open an issue in the repository.


## Project description

RICR (RicrNew) is a full-stack web application that provides a platform for showcasing mentors, experts, and success stories. It combines a modern React frontend (Vite + Tailwind) with an Express/MongoDB backend for content management and media uploads.
